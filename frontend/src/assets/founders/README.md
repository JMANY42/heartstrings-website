# Founders photo

One photo of the co-founders together, named `portrait.<ext>`.

Supported extensions: `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`, `.gif`. It is
picked up automatically at build time (see `src/data/founders.ts`).

Landscape works best — it is cropped to roughly 4:3 on a phone and 3:2 beside
the mission statement on a desktop screen.

Until the file is here, the section borrows the first home page gallery image
so nothing renders empty.
